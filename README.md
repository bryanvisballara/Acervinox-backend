# acervinox

Landing y API de acervinox. El frontend es Vite + React. El backend es Node + Express + MongoDB.

## Local

```bash
yarn
cp .env.example .env
yarn dev:all
```

- Web: http://localhost:5173
- API: http://localhost:3000/api/health

En Render el Build Command es `yarn` y el Start Command es `yarn start`. Las claves van solo en Environment, nunca en git.
